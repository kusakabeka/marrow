# Что такое AST (abstract syntax tree)

В любом языке программирования код — это просто строка, а компилятору удобнее
обрабатывать дерево, в котором узлами будут являться самые разные конструкции
языка: операции, типы, инициализация переменных и т. д.

## ast.ml

Это индуктивное определение. Зададим вспомогательные конечные множества:

Бинарные операции:
$\text{Binop} = \lbrace \text{Add}, \text{Sub}, \text{Mul}, \text{Div}, \text{Eq}, \text{Neq}, \text{Lt}, \text{Le}, \text{Gt}, \text{Ge}, \text{And}, \text{Or} \rbrace$

- Add — сложение: `+`
- Sub — вычитание: `-`
- Mul — умножение: `*`
- Div — деление: `/`
- Eq — равенство: `==`
- Neq — неравенство: `!=`
- Lt — строгое отношение порядка «меньше»: `<`
- Le — нестрогое отношение порядка «меньше»: `<=`
- Gt — строгое отношение порядка «больше»: `>`
- Ge — нестрогое отношение порядка «больше»: `>=`
- And — конъюнкция: `&&`
- Or — дизъюнкция: `||`

Унарные операции:
$\text{Unop} = \lbrace \text{Neg}, \text{Not} \rbrace$

- Neg — противоположный элемент: $\text{Neg} : \mathbb{Z} \to \mathbb{Z},\ \forall a \in \mathbb{Z} : a \mapsto -a,\ a + (-a) = 0$
- Not — логическое отрицание: `!`

Состояния переменных:
$\text{Mut} = \lbrace \text{Immutable}, \text{Mutable} \rbrace$

- Mutable — изменяемость
- Immutable — неизменяемость
