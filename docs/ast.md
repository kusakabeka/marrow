# Что такое AST(abstract syntax tree)
В любом языке программирования код это просто строка, а компилятору удобнее обрабатывать дерево, в котором узлыми будут являться самые разные конструкции в языке, например: операции, типы, инициализация переменных и. тд

## ast.ml
Это индуктивное определение. Зададим вспомогательные конечные множества:

Бинарные операции:
$Binop = \{Add, Sub, Mul, Div, Eq, Neq, Lt, Le, Gt, Ge, And, Or\}$

- Add - сложение: $+$
- Sub - вычитание: $-$
- Mul - умножение: $*$
- Div - деление: $/$
- Eq - равенство: $==$
- Neq - неравенство: $!=$
- Lt - строгое отношения порядка "меньше": $>$
- Le - нестрогое отношение порядка "меньше": $<=$
- Gt - строго отрношение порядка "больше": $>$
- Ge - нестрогое отношение порядка "больше": $>=$
- And - конъюнкция: $\&\&$
- Or - дизъюнкция: $\|\|$

Унарные операции:
$Unop = \{Neg, Not\}$

- Neg - противоположный элемент: $Neg: \mathbb{Z} \to \mathbb{Z}, \forall a \in \mathbb{Z}: a \mapsto -a, a + (-a) = 0$
- Not - логическое отрицание: !

Состояния переменных:
$Mut = {Immutable, Mutable}$

- Mutable - изменяемость
- Immutable -неизменяемость
